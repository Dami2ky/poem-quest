# 📜 诗词大闯关

课本诗词挑战网页游戏——一年级到高三语文课本古诗词全收录,按年级闯关,
选择题 + 填空题 + 双人对战 + 诗人图鉴收集。

**▶ 在线游玩:https://dami2ky.github.io/poem-quest/**

## 玩法

- **📖 年级闯关**:选年级 → 选择题(接下句 / 作者)或填空题(点选字池填空,无需输入法),
  每轮 3 颗心,按剩余心数评星
- **⚔️ 双人对战**:轮流答题计分(答对 +10,手快再加分),历史战绩累计
- **👤 诗人图鉴**:答对诗人的题即解锁 TA 的名片(33 位课本诗人,含小传与代表作)——收集控杀手锏

## 本地运行

零依赖、零构建:下载本仓库,双击 `index.html` 即可游玩。
